\begin{frame}{CNBC on JPMorgan, 9/30/2025}

Derek Waldron, JP Morgan Chief Analytics Officer:
\begin{itemize}
\item (What we're working towards is that) every employee will have their own personalized AI assistant; every process is powered by AI agents, and every client experience has an AI concierge.
\item You'll still have people at the top who are managing and have relationships with clients, but many, many of the processes underneath are now being done by AI systems.
\end{itemize}


Workers would shift from being creators of reports ... or "makers" ... to "checkers" or managers of AI agents doing that work.

\begin{frame}{Brookings Institute, 2025}

\begin{itemize}
\item As AI models begin to handle underwriting, compliance, and asset allocation, the traditional architecture of financial work is undergoing a fundamental shift.
\item As job descriptions evolve, so does the definition of financial talent. Excel is no longer a differentiator. Python is fast becoming the new Excel. 
\item But technical skills alone will not cut it. The \alert{most in demand profiles today are those that speak both AI and finance}.
\end{itemize}
\end{frame}

\begin{frame}{What Should We Teach about AI?}

\begin{itemize}
\item Where is the world going?
\begin{itemize}
\item Point-and-click GUIs will be replaced by agentic chatbots.
\item OpenAI this month introduced OpenAI apps.  
\begin{itemize}

Zillow, \ldots 
\item Provided tools for developers to create other apps

\end{itemize}
\pause
\item We can help students get to the future today
\begin{itemize}

\end{itemize}
\pause
\item These skills will be valuable to students and to employers
\end{itemize}

\end{frame}



\begin{frame}{Principles (Should Remain Constant)}
\begin{enumerate}
\item Working with AI is a dialogue: prompt, evaluate, iterate
\item AI doesn't do numbers, so it needs to generate code
\item AI is just a tool, and domain knowledge remains important 
\pause
\item Domain knowledge + AI + code $\Rightarrow$ \textcolor{orange}{$\star$\textbf{\textsc{Superstar}}$\star$}
\end{enumerate}
\end{frame}

\begin{frame}{Tools (Definitely Not Constant!)}
\begin{itemize}
\item In the past, I used Julius.ai, which is an easy-to-use chatbot with a `Code Interpreter' connected to Anthropic or OpenAI models.
\item But, Anthropic's MCP (11-25-2024) and now Claude Skills (10-16-2025) have changed the game.
\item Skills are customized prompts.  Claude only reads them when needed, so you can have many without overloading the context window. 
\end{itemize}
\end{frame}



\begin{frame}{Claude Code or Claude Desktop?}
\begin{itemize}
\item As AI has improved in general, the advantage of a chatbot that can execute terminal commands over one that cannot has grown.
\item With Claude skills, Claude Code is a general agent.
\item So, I think it is time to use a professional setup: Python, Claude Code, and VS Code.  Install Claude Code.  Let Claude Code install everything else.
\item If not that, then Claude Desktop.  But, best: Claude.ai for every finance course, Claude Code for course on AI in Finance.
\end{itemize}
\end{frame}

\begin{frame}{Claude Example}
First, install Excel and Word skills (\url{https://github.com/anthropics/skills}).  
Ask Claude to do it after researching how (just downloads text files to the right folders).  Only has to be done once.


\vspace{1em}
Claude prompt (after uploading \textit{Valuing Wal-Mart 2010}):

\vspace{1em}
\begin{quote}
Read the uploaded case. Ignore the valuation method described in the case. Do a two-stage DCF valuation. Document your assumptions and your reasons for them. Create a professionally formatted Excel workbook. 
\end{quote}
\end{frame}

\begin{frame}{Teaching Process}
\begin{itemize}
\item Discuss financial analysis issue 
\item Ask AI to solve 
\item Discuss how to verify solutions
\item Discuss how to improve prompts to get better and faster output 
\item Codify prompts and code produced by AI as Claude skill
\end{itemize}
\end{frame}

\begin{frame}{Assessment}
    Group projects:
    \begin{itemize}
        \item Financial analysis (submit chat, product, and written assessment).  Defend assignments orally.
        \item Build Claude skills for financial analysis (submit skill and description of how they verified it). 
    \end{itemize}

\vspace{1em}

    In-class seated exam: Analyze a case and prepare Excel/Word/\ldots reports \alert{using AI}.
\end{frame}
